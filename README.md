# 日本の運転れんしゅう（Japan Driving Practice）Ver.3.0

日本で運転する外国の方・ペーパードライバー・免許を取りたい人のための、運転練習アプリです。
1ファイルのHTML（外部ライブラリなし）。GitHub Pages にそのまま置けます。

## 公道を走る（Ver.3.0〜）

地図データ（OpenStreetMap）を読み込み、本物の道の形・信号・一時停止・踏切・一方通行・制限速度でコースを走るモード。タイトルの「公道を走る（実際の道路データ）」から入る。

- **場所の選び方**：「佐賀県の教習所を一覧で見る」（地図データに登録された教習所。佐賀県の周辺を含む）／場所の検索（例：佐賀駅）／現在地／サンプルの町（架空・ネットなしで試せる）。選んだ場所の周り約2km四方を読み込む（10〜40秒）
- **コースの作り方**（3つ）
  - 地図を押す：🚗 がスタート。押した順に通る点が増え、道にそってコースを作る（一方通行も守る）
  - GPXを読み込む：実際に車で走ってスマホで記録した道すじを、地図の道にあてはめてコースにする
  - 自動で作る：スタートから出て戻る周回コース（約2.5km、右左折を含む）
  - 「このコースのURLをコピー」で共有（公開版で開くと、そのコースが読み込まれる）
- **走り方**：「練習で走る（教官つき）」または「路上検定で走る（採点）」。緑の線がコース。右左折の手前で合図を求める
- **採点**：信号無視（検定中止）、一時停止（停止線の直前で止まり左右を見る）、踏切（直前で止まり左右を見る、警報中は進入で中止）、一方通行の逆走（検定中止）、左側通行（中央線のある道は厳しめ、狭い道は少しゆるめ）、制限速度（標識の値。標識がなければ、中央線のある道は60km/h、ない道は30km/h）、合図、横断歩道の歩行者、脱輪（道幅＋路肩0.8m）
- **交通**（「ほかの車・歩行者・列車を出す」でオン／オフ）
  - ほかの車：道を走り、信号を守り、前の車や歩行者で止まる。交差点では近づいてくる自分の車に道をゆずる
  - 歩行者：横断歩道を渡る（車が近いときは渡り始めない）
  - 列車：線路を走り、近づくと踏切の警報が鳴って遮断機が下りる
- **注意**
  - 地図データは Claude の画面の中のプレビューでは読み込めない。公開版（GitHub Pages）で使う。サンプルの町はどこでも使える
  - 地図データは誰でも編集できるものなので、信号・標識・速度・道幅が現地と違うことがある。教習所の実際の検定コースは公開されていない
  - 地図データ © OpenStreetMap contributors（ODbL）。画面に表示している
  - 使っている外部サービス：Overpass API（地図データ）、Nominatim（場所の検索）。混んでいると読み込めないことがある

## 教習所モード（Ver.2.0〜）

PlayStation の教習所ゲームのように、入校から仮免許までを1本の流れで進めるモード。タイトルの「教習所に入校する（免許をとろう）」から入る。

| 段階 | 中身 | 合格の条件（アプリの目安） |
|---|---|---|
| 第1段階 技能教習（10） | レッスン1〜10。前のハンコがあると次が受けられる | 最後まで走り、検定中止にあたるミスがなく、注意が2つ以下 |
| 学科教習（3） | 学科1 標識、学科2 交通ルール、学科3 危険予測。いつでも受けられる | 10問中8問以上 |
| 修了検定 | 技能10・学科3のハンコがそろうと受けられる。コースAかBを走る | 70点以上・検定中止なし |
| 仮免学科試験 | 修了検定に合格すると受けられる。標識とルールから20問 | 20問中18問以上（90%）。本物は文章問題50問・90%以上 |
| 仮免許 | 合格すると「このアプリの修了証」を表示（公的な免許ではないと明記） | — |

- 教習原簿：合格した項目に赤いハンコ（桜井教官・日付）。名前（ニックネーム）を入れられる。記録はこの端末のブラウザに保存（別の端末とは共有されない）。「原簿を最初からやり直す」で消せる
- 助手席の教官「桜井教官」（オリジナルのキャラクター。ちょっと厳しいが親切）
  - ミスをするとすぐ短く注意（例：「脱輪だ！ 止まって、バックで戻そう」）、ミスなく進むとほめる
  - 次の指示を読み上げる（ブラウザの読み上げ機能。声は端末によって違う）
  - レッスンでは、曲がる前にウインカーが出ていないと「そろそろウインカーを出そう」
  - 補助ブレーキ：道路の上の歩行者・自転車・列車にぶつかりそうになると教官がブレーキを踏む。レッスンでは注意1つ、検定では検定中止
  - 設定で、教官の表示と声をそれぞれオフにできる

## できること（Ver.1）

| 入口 | 中身 |
|---|---|
| まなぶ（レッスン） | 1.発進と停止（AT・クリープ） 2.左折・右折と合図 3.一時停止と安全確認 4.信号と横断歩道 5.踏切 6.S字 7.クランク 8.方向変換 9.縦列駐車 10.自転車の横を通る（2026年4月〜） |
| 検定コース | コースA（信号・一時停止・横断歩道・S字・方向変換・指示速度）／コースB（縦列駐車・踏切・クランク・信号）。100点から減点、70点以上で合格（アプリの目安） |
| 自由に走る | 教習所コースを自由に。歩行者・自転車・列車・信号が動く |
| 標識クイズ | 15種類の標識・マーク |
| 交通ルール問題集 | 17問（赤信号で左折できない、生活道路30km/h〈2026年9月〜〉、自転車の側方通過〈2026年4月〜〉、外国免許・外免切替〈2025年10月〜〉など） |
| 危険予測 | 8場面。答えると「見えにくい危険」が絵に出る |
| ルールブック | ルールと標識の一覧 |

- 車両：乗用車（AT）。トラック・二種・バイク・トラクター・ショベルは「準備中」として表示
- 言語：日本語・やさしい日本語・English・Tiếng Việt・中文・Bahasa Indonesia（初回はブラウザの言語で自動選択）
  - やさしい日本語は画面の文言のみ。問題文は通常の日本語で表示
- 画面：運転席ビュー（右ハンドル、ルームミラー・左右ミラー、Aピラー）＋上から見たビュー（タップで全体図／拡大）
- 操作：ハンドル（ドラッグで回す・手をはなすと戻る）、ペダル（押す位置が下ほど深く踏む）、P/R/N/D、パーキングブレーキ、シートベルト、ウインカー（曲がり終わると自動で戻る）、安全確認（左・右後ろ・右を見る）
- キー：標準は ↑/W アクセル、↓/S ブレーキ、←→/A D ハンドル、F ハンドルをまっすぐ、1〜4 でP/R/N/D、Q/E ウインカー、B パーキングブレーキ、V シートベルト、Z/X/C 安全確認、Tab 表示、M 地図。運転画面の「⌨ キー操作の設定」（または設定）で自由に変えられる
- 補助表示（設定）：予想進路線、ルート案内、タイヤの跡、ミラー、音、ハンドルの速さ

## 採点（アプリ独自の目安）

| 項目 | 減点 |
|---|---|
| 脱輪・ポール接触・右側通行 | −20 |
| 一時不停止 | −20 |
| 停止位置が遠い・安全不確認・速度超過（45km/h超）・指示速度に達しない・合図なし・自転車との間隔・シートベルト・発進前の確認なし | −10 |
| 合図がおそい・発進の合図なし・パーキングブレーキのまま走行・切り返し | −5 |
| 信号無視・踏切不停止・警報中の踏切進入・横断歩道の歩行者妨害・衝突・脱輪のまま進行 | 検定中止 |

合図は「曲がる地点の約15m手前」でウインカーが出ているか、2秒以上前から出ているかで判定。続けて曲がる短い区間では「おそい」は判定しない。

## コースの寸法（m）

外周 126×71（道幅7m・左回り）、中央の十字路は信号つき。S字幅4.0m（曲線半径7m）、クランク幅4.5m、方向変換の道7m・車庫2.5×5.5m、縦列駐車の道6m・枠2.5×7m。
車は全長4.4m・幅1.7m・ホイールベース2.6m・最大切れ角36°（最小回転半径 約5.0m）。クランク・車庫・縦列は、この車で通れることを自動テストで確認済み。

## 確認したこと（Ver.1）

- Playwright（Chrome）で、検定コースA・B、レッスン1・8・9・10を自動運転し、採点と手順の進み方を確認
- スマホ縦（390×844）・横（844×390）・PC（1280×860）で表示を確認。各言語で文字のはみ出しを確認
- テスト用の窓口：開発者ツールで `window.__jdp`

## 公開のしかた（GitHub Pages）

1. GitHub（Sakamoto20220205）で Public のリポジトリを作る（例：japan-driving-practice）
2. `index.html` と `README.md` をアップロード（Add file → Upload files → Commit changes）
3. Settings → Pages → Build and deployment の Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://sakamoto20220205.github.io/リポジトリ名/` で開ける

更新するときは、新しい `index.html` を同じ名前でアップロードして上書きする。画面右下の版（Ver.）で、公開中の版を確認できる。
